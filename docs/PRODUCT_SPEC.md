# Product specification

Arcane Commons v1 is a public reference implementation for communities that
want individual sovereignty, institutional continuity and attributable creator
reward. It joins an encrypted cooperative data mesh to eight portable protocol
domains: Research, Spell, Capability, Compute-to-Data, Pensive, Grimoire,
Legacy and federation/export.

Owners keep plaintext, identity seeds and recovery keys. A Commons may publish
signed records, encrypted envelopes, content identifiers, bounded permissions,
attestations and explicit revenue splits. Payment never grants governance
weight. Research corrections and failures remain causal records rather than
being silently rewritten. Every export has an owner signature, ordered Merkle
root and target receipt.

The desktop provides the complete eight-stage local composition journey and
encrypts its saved state with a Stronghold-held vault key. The API persists only
authenticated, community-scoped encrypted artifacts whose CID and owner
signature verify. The CLI independently checks the connected eleven-step
protocol journey.

v1 is a reference implementation, not a hosted production network. The
confidential-compute attestation is a verifiable adapter boundary and local
measurement allow-list, not proof of a real certified TEE. Revenue allocation
is deterministic accounting, not card/bank/crypto settlement. The local
three-node demo runs on one computer and is not geographic redundancy. There is
no anonymity, Byzantine consensus, wallet, cryptocurrency or security-audit
claim.
